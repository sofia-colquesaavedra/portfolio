# Portfolio — Sofía Colque Saavedra

Sitio estático bilingüe (ES/EN) sin dependencias ni build.

- `index.html` — home. `case.html?id=<id>` — casos de estudio.
- `assets/js/content.js` — **todos los textos** (ES y EN), casos, otros trabajos y links. Para editar contenido, solo tocá este archivo.
- `assets/js/visuals.js` — ilustraciones SVG de los casos (reemplazables por imágenes reales).
- `assets/css/styles.css` — estilos y design tokens (`:root`).

## Ver en local

```bash
python3 -m http.server 8080
```

## Publicar

Funciona tal cual en GitHub Pages, Netlify o Vercel (sitio estático, carpeta raíz).
